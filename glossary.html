Sensor & Optics

感光元件與光學

CMOS
Complementary Metal-Oxide-Semiconductor
主流影像 sensor 技術,每 pixel 都有自己的放大器。
CFA
Color Filter Array
每 pixel 上的彩色濾鏡,最常見 Bayer pattern(RGGB)。
FSI / BSI
Front-side / Back-side Illuminated
sensor 結構演化:BSI 把感光區翻到上面,光不用穿過金屬層。
QE
Quantum Efficiency
光子轉電子的機率,好 sensor 約 80%。
DCG
Dual Conversion Gain
同次曝光、雙 gain 讀出,提升動態範圍且無 ghosting。
QPD
Quad Phase Detection
每 pixel 內 2×2 photodiode,可水平/垂直雙向相位對焦。
CRA
Chief Ray Angle
光線入射 sensor 的主光線角度,影響 lens shading。
VCM
Voice Coil Motor
推動鏡片組或 sensor 做 AF / OIS 的電磁線圈馬達。
OTP
One-Time Programmable
sensor 內小型非揮發儲存,存出廠校正資料(defect map、LSC table)。
MIPI & Interface

介面與資料流

MIPI
Mobile Industry Processor Interface
手機晶片介面標準的聯盟。
CSI-2
Camera Serial Interface v2
MIPI 規範的 camera 資料介面,packet-based。
D-PHY
Differential PHY
傳統 MIPI 實體層,差分對 + clock lane。
C-PHY
3-wire PHY
較新的 MIPI 實體層,3 條為一組 trio,clock 內嵌。
VC
Virtual Channel
CSI-2 packet header 內的 2-bit 標識,讓一條 MIPI 跑多個 stream。
LP / HS
Low-Power / High-Speed
D-PHY 兩種訊號模式,idle 時 LP 省電、傳資料時 HS 高速。
SCCB
Serial Camera Control Bus
I²C 的變體,sensor 設定常用。
I3C
Improved Inter-Integrated Circuit
新一代 I²C,12MHz 速度,降低 3A latency。
DT
Data Type
CSI-2 packet header 內的 6-bit 標識,指明資料格式(RAW10、YUV420 等)。
ISP Pipeline

ISP 各區塊

ISP
Image Signal Processor
影像訊號處理器,SoC 內專用硬體區塊。
BLC
Black Level Correction
把 sensor 暗電流 offset 減掉,讓黑真的是 0。
LSC
Lens Shading Correction
補正鏡頭造成的中亮邊暗、邊緣色偏。
DPC
Defect Pixel Correction
偵測並修補 sensor 上的死點與壞點。
Demosaic
CFA Interpolation
把 Bayer 單通道還原成 RGB 三通道。
WB
White Balance
根據光源色溫調 R/B gain,讓白色看起來是白色。
CCM
Color Correction Matrix
3×3 矩陣,把 sensor 色域映射到 sRGB / P3。
NR
Noise Reduction
去雜訊,有空域(SNR)與時域(TNR)兩派。
TNR / MFNR
Temporal / Multi-Frame Noise Reduction
跨幀對齊後平均,SNR 提升 √N 倍。
LTM
Local Tone Mapping
區域性壓動態範圍,手機 HDR 風格的主角。
GTM
Global Tone Mapping
整張一條曲線,簡單但對高對比場景不夠。
NLM
Non-Local Means
在全圖找相似 patch 一起平均的進階去噪。
BM3D
Block-Matching 3D Filter
學術級去噪演算法,精度高但運算量大。
3A & AF

自動曝光、對焦、白平衡

AE
Auto Exposure
自動曝光,目標讓畫面平均亮度落在 18% 灰附近。
AF
Auto Focus
自動對焦,目標讓主體最銳利。
AWB
Auto White Balance
自動白平衡,估計光源色溫並反向補正。
CDAF
Contrast-Detection AF
掃描 VCM 找對比最大位置,慢但精度高。
PDAF
Phase-Detection AF
用 sensor 上的半遮罩 pixel 量相位差,快。
2PD / Dual-Pixel AF
Dual-Photodiode AF
每 pixel 內 2 個 photodiode,全 sensor PDAF。
ToF
Time of Flight
發雷射量反射時間直接算距離。
Multi-Frame & HDR

多幀融合與動態範圍

HDR
High Dynamic Range
高動態範圍,兼顧亮暗細節。
SDR
Standard Dynamic Range
傳統 8-bit / 100 nits 動態範圍。
HDR10 / HLG / PQ
HDR 編碼標準
HDR10 是 10-bit、HLG 是廣電用、PQ 是 Dolby Vision 基礎。
ZSL
Zero Shutter Lag
用 ring buffer 讓快門延遲為零。
Bracketing
Exposure Bracketing
拍多張不同曝光,常用於傳統 HDR。
Staggered HDR
Staggered Exposure HDR
sensor 端交錯輸出多曝光,合成更即時。
Ghost Removal
Motion Ghost Removal
HDR / MFNR 合成時,把運動區域改用單張避免重影。
Video & Stabilization

影片與防抖

OIS
Optical Image Stabilization
光學防抖,VCM 即時推動鏡片或 sensor。
EIS
Electronic Image Stabilization
電子防抖,用大畫面 crop 補抖動,有 crop loss。
IMU
Inertial Measurement Unit
三軸或六軸慣性感測器,提供 gyro 資料給 OIS / EIS。
Rolling Shutter
逐行曝光
CMOS sensor 一行一行讀,造成 skew、jello、flash banding。
Global Shutter
整張同時曝光
無 skew,但 pixel 大、貴,手機罕見。
Optical Flow
光流
估算每 pixel 在連續幀間的位移向量。
Encoder

影片編碼

H.264 / AVC
Advanced Video Coding
2003 年標準,目前最廣相容性。
H.265 / HEVC
High Efficiency Video Coding
壓縮比約 H.264 兩倍,手機錄影主流。
AV1
AOMedia Video 1
免授權的新一代 codec,YouTube / Netflix 主推。
I / P / B frame
Intra / Predicted / Bi-directional
關鍵幀 / 前向參考 / 雙向參考,壓縮比遞增,延遲也遞增。
GOP
Group of Pictures
兩個 I frame 之間的所有 frame 集合,通常 1~2 秒。
CBR / VBR / CRF
Rate Control Modes
固定 bitrate / 可變 bitrate / 固定畫質。
ME
Motion Estimation
encoder 找參考幀位移,占整體運算 50% 以上。
AI & NPU

AI 與運算單元

NPU
Neural Processing Unit
專用 AI 加速器,主要做矩陣乘法。
CNN
Convolutional Neural Network
卷積神經網路,影像 AI 的主流架構。
Semantic Segmentation
語意分割
每 pixel 都被分類,輸出 segmentation mask。
SR / Super-Resolution
超解析度
用 CNN 把低解析放大成高解析,推測細節。
Multi-frame SR
多幀超解析
利用手抖 sub-pixel 位移,真實提升資訊量。
Performance Metrics

系統度量指標

SNR
Signal-to-Noise Ratio
訊號/雜訊比,單位 dB,> 30dB 可接受。
MTF
Modulation Transfer Function
解析力的量化指標,常用 MTF50。
DR
Dynamic Range
最亮/最暗比值,單位 dB 或 EV stops。
M2P
Motion-to-Photon Latency
實體動 → 螢幕更新,AR / VR 關鍵指標。
Shutter Lag
按下到開始曝光
ZSL 讓這個近乎為零。
Shot-to-Shot
連拍間隔
兩張之間的延遲,影響連拍體感。
Platform & Stack

平台與軟體堆疊

HAL3
Hardware Abstraction Layer v3
Android Camera 的 vendor HAL 介面標準。
CamX + Chi-CDK
Qualcomm Camera Framework
Qualcomm 平台上的 HAL3 實作,智慧眼鏡開發必碰。
MTKCAM
MediaTek Camera HAL
聯發科平台的 camera HAL 實作。
DMA-buf
DMA Buffer Sharing
Linux 機制,讓 sensor / ISP / encoder 之間 zero-copy 傳 buffer。
v4l2
Video for Linux 2
Linux 上 video 設備的 API。
AR1 Gen 1
Qualcomm Smart Glasses SoC
2023 年發表的智慧眼鏡專用 SoC。
