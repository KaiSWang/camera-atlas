Camera-AI 與 Semantic ISP
讓 ISP 看懂畫面在拍什麼

傳統 ISP 對每個 pixel 一視同仁。AI ISP 不一樣——它先「看懂」這張圖在拍什麼, 再對不同區域給不同處理。臉上磨皮、天空降噪、食物增加飽和度、文字銳化—— 這些都是 semantic ISP 的工作。這一章把 NPU、CV pipeline、semantic 處理串起來。

Section 01 · NPU 在 camera 中的角色

為什麼 ISP 不夠 需要另一塊運算單元

傳統 ISP 是「固定 pipeline」——每個 block 都是 hard-wired 的運算,進什麼出什麼。 AI 運算需要可程式化的矩陣乘法(MAC array)——這是 NPU 的拿手好戲。 所以現代 camera pipeline 不是 ISP 取代,而是 ISP + NPU 共生。

▸ ISP 與 NPU 在 pipeline 的協作

ISP 仍是骨幹,但 NPU 在兩個層次介入:(1) 輕型 AI 即時提供 metadata 引導 ISP 處理;(2) 重型 AI 在 multi-frame 階段做 denoise / super-res 等密集運算。

Section 02 · Semantic Segmentation

畫面分區 每個像素都被打標籤

Semantic segmentation 是 camera-AI 的基石。CNN 把每個 pixel 分類成 「天空 / 皮膚 / 草地 / 文字 / 食物 / 建築」等類別,輸出一張「segmentation mask」 跟原圖一樣大。ISP 拿這張 mask 對不同區域做不同處理。

01

典型網路結構

手機上跑的 segmentation 不是 ImageNet 那種重型模型,而是輕量化版—— 常見如 MobileNetV3 + DeepLabv3+、UNet-tiny。模型大小 1~5MB, inference 時間 5~15ms,跑在 NPU 上幾乎不耗電。

02

解析度妥協

原圖 4K 太大,sensor 端就降採樣到 256×256 或 512×512跑 segmentation, 再把結果上採樣回原解析度。所以 mask 的邊緣會有一點「鋸齒」或「過於圓滑」。 ISP 用 mask 時通常會加 guided filter 細化邊緣。

03

應用到 ISP 的方式

常見三種:(1) 區域 NR 強度——天空用強去噪、人臉適度; (2) 區域 sharpening——文字加強、皮膚減弱(磨皮); (3) 區域 saturation——食物加強紅黃、藍天加強藍。 這就是「AI 拍照」感覺特別「對胃口」的原因。

Segmentation 失敗會怎樣
  • 誤分天空為皮膚——天空被磨皮,出現詭異的「平滑感」
  • 頭髮 mask 邊緣不準——人像模式「割掉」一綹頭髮,變成 floating 髮絲
  • 反光金屬被判為天空——車身、玻璃出現不應該的去噪痕跡
Section 03 · Face & Object Detection

找東西 比認東西簡單,但要快

Face detection 是 camera-AI 的最早入口——影響 AE 加權、AF 對焦點、ZSL 快門時機。 現代手機不只偵測有沒有臉,還偵測「臉的方向、表情、是否閉眼」, 作為 ZSL 取幀依據(避開閉眼的那張)。

A

輕量 detector

預覽路徑要每幀都跑,所以用非常輕的 anchor-based detector—— BlazeFace、MTCNN tiny。每幀只跑 2~5ms。一張臉的輸出是bounding box + 5~6 個 landmark (兩眼、鼻、嘴角)。

B

Eye state classifier

截下兩眼 patch,跑個超小的 CNN 判斷「開 / 半開 / 閉」。ZSL ring buffer 取幀時, 優先選所有人都睜眼的那張——這就是為什麼合照成功率比按下快門那一刻高。

C

場景識別(Scene Classifier)

全圖跑分類器,輸出「夜景 / 美食 / 風景 / 文件 / 寵物 / 雪景」等場景標籤。 每個場景對應一組 ISP 參數預設值——這就是手機相機 app 上面那個小標籤 (例如三星的「自動場景」、小米的「AI camera」)。

Section 04 · AI Denoise & Super-Resolution

用神經網路 畫出原本看不到的細節

傳統 NR 在「不模糊細節」與「不留雜訊」之間掙扎。AI denoise 用 CNN 學「雜訊 raw → 乾淨 raw」的映射, 同時去雜訊與保留細節。Super-resolution(SR)則是把低解析度放大到高解析度, 推測「原本沒記錄的細節」。

D

AI Denoise — 訓練資料是關鍵

訓練需要「乾淨」與「雜訊」配對。怎麼弄?三種方法: (1) 真實配對——拍兩張,一張長曝低 ISO(乾淨),一張短曝高 ISO(雜訊),很費功; (2) 合成雜訊——對乾淨 raw 加 Poisson + Gaussian noise model; (3) Self-supervised——只用單張雜訊圖,某些 loss function 也能學 (如 Noise2Noise)。

E

Super-Resolution

最常見場景:數位變焦。傳統 2× 變焦就是截圖放大,糊。AI SR 用 CNN 根據已知 pixel 推測高解析度版本,效果驚人——iPhone「Pro RAW」與 Pixel「Super Res Zoom」 背後的核心技術。

進階版用「multi-frame super-res」:利用手抖在每幀間造成的sub-pixel 位移, 把多張圖合成出一張「真的多了資訊」的高解析圖,而不是純粹「猜」。Google Pixel 用這招把 1× 鏡頭 數位變焦推到 7×。

Section 05 · Semantic ISP 的趨勢

從「對 raw 做事」到「對內容做事」ISP 哲學的轉向

過去 10 年,ISP 哲學從「處理每個 pixel」轉向「處理每個物體」。 面試官會問:你怎麼看 ISP 的未來?有幾個趨勢值得提。

五個正在發生的趨勢
  • Region-adaptive ISP——同樣 IP 但每個 segment 用不同參數,逐漸取代「整張一套參數」
  • Computational photography 平民化——MFNR / HDR / night mode 從旗艦下放到中階
  • Sensor 自帶 AI——Sony IMX800 系列開始內建小型 AI 加速器,直接出 metadata
  • End-to-end neural ISP——研究級嘗試用一個大 CNN 替代整條 ISP,商用化還早
  • Always-on event-driven camera——智慧眼鏡用的方向,只在「值得看」時才喚醒主 pipeline
Section 06 · 本章重點回顧

Camera-AI 面試重點

技術觀念
1 → ISP + NPU 共生,不是替代——ISP 仍是骨幹
2 → Semantic segmentation 是核心——逐 pixel 標籤後讓 ISP 區域處理
3 → 輕量 detector 跑預覽,重型 CNN 跑 capture
4 → AI denoise 訓練資料:真實配對 / 合成 / self-supervised
5 → Multi-frame super-res 利用手抖 sub-pixel 位移,真正提升資訊量
6 → Sensor 自帶 AI 是智慧眼鏡 always-on 的關鍵方向
