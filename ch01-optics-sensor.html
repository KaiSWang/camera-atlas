光路與感光元件
從 一顆光子如何變成 bit 開始

Camera pipeline 的起點不是 ISP,也不是 sensor 晶片,而是一顆光子打進鏡頭那一刻。 你要懂為什麼夜景照需要 multi-frame、為什麼 rolling shutter 拍轉動的螺旋槳會變香蕉、 為什麼智慧眼鏡不能塞下 1 吋大底——答案都在這一章。

Section 01 · 光路

光從鏡頭到 photodiode 會經過多少道關卡

一個現代手機 camera 模組,從外到內大致是:鏡頭組(多片塑膠/玻璃鏡片)→ IR cut filter → micro-lens 陣列 → color filter array → photodiode → readout circuit。 光子在這條路上一直在「掉」——每一層都會吸收或反射掉一部分。

01

鏡頭組(Lens stack)

塑膠鏡片 6P / 7P / 玻塑混合

手機鏡頭通常 6 到 8 片(6P 表示 6 plastic),負責聚光、校正像差、調整焦距。 光圈 f/1.6 大概代表「鏡頭口徑 = 焦距 / 1.6」,光圈愈大進光量愈多,但邊緣的像差(aberration) 也愈難壓。一個 28mm 等效焦距、f/1.8 的鏡頭,通光面積大約是 f/2.8 的 2.4 倍。

02

IR cut filter

CMOS sensor 對紅外線非常敏感,但人眼看不見紅外線。為了讓拍出來的顏色「像人眼看到的」, 必須在 sensor 前放一片 650nm 左右開始截止的 IR filter。 這也是為什麼一般 camera 看不到電視遙控器的紅外線 LED——除非你把這片濾鏡拿掉(改造夜視相機)。

03

Micro-lens array

每一顆 pixel 上面都有一顆微透鏡,把斜射進來的光「導正」到 photodiode 中央。 這對小 pixel 特別重要——pixel 愈小,周邊光線愈容易打在金屬線路上而不是感光區。 CRA(Chief Ray Angle)不匹配時就會出現嚴重 lens shading,這也是後面 LSC 校正 要處理的事。

04

Color filter array(CFA)

Bayer pattern 的歷史意外

每一顆 pixel 只會被一種顏色的濾鏡蓋住(R / G / B)。最常見的排列是 Bayer pattern (RGGB),綠色佔一半,因為人眼對綠色最敏感。所以一張 12MP 的 raw 圖,其實只有3MP 紅、 6MP 綠、3MP 藍——剩下的顏色資訊全靠後面的 demosaic 演算法「猜」出來。

05

Photodiode & readout

光子打進矽基板後,以「機率」激發出電子——這個機率叫 QE(Quantum Efficiency,量子效率), 好一點的 BSI sensor 大概 80%。電子被累積在 well 裡,曝光結束後透過 floating diffusion 轉成電壓,再經過 column ADC 變成數位值。整個過程就是「光 → 電子 → 電壓 → bit」。

關鍵概念 · 為什麼這些細節對系統工程師重要
  • QE 決定 SNR 下限——QE 愈低,同樣光強下產生的電子愈少,雜訊相對佔比愈高
  • Pixel size 與感光能力——pixel 面積愈大,單位時間吸收的光子愈多,動態範圍與 SNR 都更好
  • Lens MTF 是 pipeline 的上限——再好的演算法也救不回鏡頭沒解析出來的細節
Section 02 · CMOS Sensor 結構

FSI、BSI、Stacked 三代演化背後的物理直覺

CMOS sensor 從 2000 年代演化到現在,經歷了三個世代——你可以把它想成是「光要走多遠才能到達感光區」 的優化過程。每一代都是為了在 pixel 變小、解析度變高的同時,保住感光能力。

▸ FSI、BSI、Stacked 三代結構比較

三代 CMOS sensor 結構演化:FSI(光要穿過金屬層)→ BSI(翻過來,光直達感光區)→ Stacked(把邏輯層疊在下面)。

Stacked sensor 為什麼是現代旗艦的標配
  • DRAM-stacked(如 Sony IMX989)讓 sensor 自己有暫存,可以做超高速讀取,例如 120fps 連拍或 1/16000s 電子快門
  • Logic layer 直接在 sensor 下做 HDR、binning、甚至小型 AI 偵測,降低主 ISP 的工作量
  • Sony 在 2022 年發表的 2-layer transistor pixel 進一步把電晶體挪到第二層,放大感光區
Section 03 · Shutter 機制

Rolling vs Global Shutter 為什麼螺旋槳會變香蕉

手機 CMOS sensor 幾乎全部都是 rolling shutter——一行一行讀出來,而不是「整張一起讀」。 這個物理限制造成一個有趣現象:拍快速移動的物體時,影像會「歪掉」。理解這件事對 video pipeline、 OIS/EIS、HDR 都有實際影響。

▸ Rolling shutter 的時間錯位

Rolling shutter 是「一行一行讀」,每行曝光起點都錯開,稱為 line time。一張 4000 行的 sensor,如果 line time 10μs,整張讀完就是 40ms。

類型 機制 優點 缺點
Rolling shutter 一行一行曝光與讀出 電路簡單、pixel 小、便宜 有 skew、jello、flash banding
Global shutter 整張同時曝光,額外儲存格 無 skew、適合機器視覺 pixel 大、貴、消費級少見
Mechanical shutter 實體簾幕 無電子滾動 體積大,手機不適用

Rolling shutter 衍生的問題包括: jello effect(影片晃動時畫面像果凍)、 flash banding(LED 燈閃爍時產生橫條紋)、 HDR 對齊困難(不同曝光行還沒讀完,場景就動了)。 所以現代手機 sensor 拼命壓低 readout time,旗艦級已經可以做到 5~8ms 整張讀完。

Section 04 · HDR Sensor

Staggered、DCG、QPD sensor 級的 HDR 三條路

傳統 HDR 是 ISP 把多張不同曝光的圖合成。但近年的旗艦 sensor 自己就能輸出 HDR raw, 把這件事「下放」到 sensor。理解這三種架構的差別,才能討論 latency、power 與畫質的取捨。

A

Staggered HDR(交錯曝光)

Sony / Samsung / OmniVision 都有用

連續輸出 2~3 張不同曝光時間的影像(short / medium / long),時間軸上「交錯讀出」, 然後在 sensor 或 ISP 端合成。優點是控制簡單、相容性高;缺點是不同曝光之間有時間差, 動態物體會有 ghosting。

B

DCG(Dual Conversion Gain)

同一次曝光,但 floating diffusion 有兩種容量設定:高 gain(放大暗部訊號, 適合低光)和 低 gain(壓縮亮部,避免過曝)。讀出時兩個值都拿, 合起來變成高動態範圍。優點是同時曝光、沒有 ghosting;缺點是動態範圍提升有限, 大約多 6~10dB。

C

QPD / Quad Bayer

4-in-1 binning 同時做相位對焦

把 2×2 的同色 pixel 合成一個邏輯 pixel,可以選擇: (1) 全部相加變大 pixel(低光模式); (2) 不同曝光產生 HDR; (3) 左右兩半相減做相位對焦(這就是 QPD 的核心)。 Sony IMX989 / IMX800 系列就是這個架構。

面試重點 · 為什麼 sensor 端 HDR 在智慧眼鏡很關鍵
  • 降低 ISP 工作量——sensor 直接給合成過的 HDR raw,主 SoC 不用跑 3 張合成
  • 降低 MIPI 頻寬——傳一張 HDR 比傳三張省 40% 以上
  • 降低功耗——always-on 場景下,sensor 自己處理比把資料送到 AP 省得多
Section 05 · 本章重點回顧

光路與感光元件 記住這幾件事就夠了

面試官最常問的 5 個問題
1 → Bayer pattern 為什麼綠色佔一半?因為人眼亮度感受 70% 來自綠色。
2 → BSI 比 FSI 好在哪?光不用穿過金屬線路,QE 大幅提升,小 pixel 才可行。
3 → Rolling shutter 怎麼解 jello?OIS 補光路、EIS 補後處理、加快 readout time。
4 → DCG 與 Staggered HDR 的差別?DCG 同時曝光無 ghosting,Staggered DR 更高。
5 → QPD 怎麼同時做對焦?把同色 pixel 切左右半,讀出差異 = 相位差。
